Face Mood Music Player

An ESP32 reads a face through a camera, estimates the visible expression, and plays a matching song from an SD card. Built for a school exhibition or personal prototype.

Tap an expression to see which song the player picks.

These are estimates of visible facial expressions, not guaranteed readings of someone’s real emotions.

How it works

  • Camera captures the person’s face.
  • ESP32 detects the face.
  • A small AI model estimates the expression.
  • ESP32 picks a song from the SD card.
  • DFPlayer Mini plays it through the speaker.
  • Each mood has 5 songs. When the same mood is detected again, the next song plays.

The ESP32 DevKit has no built-in camera and limited RAM, so reliable five-mood recognition on it is hard. Start with a small, quantized model, not a large one.

Components

  • ESP32 DevKit V1Main controller and AI processing.
  • OV2640 camera moduleCaptures the face. Use a 2.54 mm breakout adapter for its connector.
  • DFPlayer MiniPlays the selected MP3 files.
  • MicroSD card, 8 or 16 GBStores the songs, formatted FAT32.
  • Speaker, 4 Ω 3 WMusic output.
  • Capacitor, 470–1000 µFAcross the DFPlayer supply, to reduce power dips.
  • Also needed1 kΩ resistor for DFPlayer RX, breadboard, jumper wires, stable 5 V supply with enough current.

SD card songs

Format as FAT32. Make one folder per mood (01 to 05) with up to 5 songs in each, named 001.mp3 to 005.mp3:

SD CARD
├── 01  Happy: 001.mp3 ... 005.mp3
├── 02  Sad (motivational): 001.mp3 ... 005.mp3
├── 03  Angry (relaxing): 001.mp3 ... 005.mp3
├── 04  Neutral (soft): 001.mp3 ... 005.mp3
└── 05  Surprised (energetic): 001.mp3 ... 005.mp3

Each time a mood is detected, the player moves to that mood’s next song and goes back to 001 after 005.

AI model

Use Edge Impulse with TensorFlow Lite Micro. Train a small classifier with five classes: Happy, Sad, Angry, Neutral, Surprised. It takes a cropped face image resized to the model’s input size. Inference runs on the ESP32, so no internet is needed while it runs.

Arduino code

Install DFRobotDFPlayerMini, the ESP32 board package (includes esp32-camera) and your Edge Impulse library. This is the hardware and music framework. detectMood() returns Neutral until you connect your trained model.

#include "esp_camera.h"
#include "DFRobotDFPlayerMini.h"
#include "HardwareSerial.h"

HardwareSerial musicSerial(2);
DFRobotDFPlayerMini player;
camera_config_t config;

enum Mood { HAPPY, SAD, ANGRY, NEUTRAL, SURPRISED };
Mood currentMood = NEUTRAL;

const int SONGS_PER_MOOD = 5;
int nextSong[5] = {1, 1, 1, 1, 1};  // next file for each mood

void setupCamera() {
  config.ledc_channel = LEDC_CHANNEL_0;
  config.ledc_timer = LEDC_TIMER_0;
  config.pin_d0 = 5;  config.pin_d1 = 18;
  config.pin_d2 = 19; config.pin_d3 = 21;
  config.pin_d4 = 36; config.pin_d5 = 39;
  config.pin_d6 = 34; config.pin_d7 = 35;
  config.pin_xclk = 0;   config.pin_pclk = 22;
  config.pin_vsync = 25; config.pin_href = 23;
  config.pin_sccb_sda = 26; config.pin_sccb_scl = 27;
  config.pin_pwdn = 32;  config.pin_reset = -1;
  config.xclk_freq_hz = 10000000;
  config.pixel_format = PIXFORMAT_RGB565;
  config.frame_size = FRAMESIZE_QQVGA;
  config.jpeg_quality = 12;
  config.fb_count = 1;
  config.fb_location = CAMERA_FB_IN_DRAM;
  config.grab_mode = CAMERA_GRAB_WHEN_EMPTY;

  if (esp_camera_init(&config) != ESP_OK) {
    Serial.println("Camera error");
    while (true) delay(1000);
  }
}

// Replace with Edge Impulse face detection + emotion model
Mood detectMood() {
  camera_fb_t *frame = esp_camera_fb_get();
  if (!frame) return NEUTRAL;
  // TODO: detect face, crop, resize, run model,
  // return the highest-confidence mood.
  esp_camera_fb_return(frame);
  return NEUTRAL;  // temporary, NOT AI detection
}

void playMoodMusic(Mood mood) {
  // folder 01 to 05 = mood, file 001 to 005 = song
  player.playFolder(mood + 1, nextSong[mood]);
  nextSong[mood]++;
  if (nextSong[mood] > SONGS_PER_MOOD) nextSong[mood] = 1;
}

void setup() {
  Serial.begin(115200);
  musicSerial.begin(9600, SERIAL_8N1, 16, 17);
  if (!player.begin(musicSerial)) {
    Serial.println("DFPlayer not detected");
    while (true) delay(1000);
  }
  player.volume(22);
  setupCamera();
}

void loop() {
  Mood detected = detectMood();
  if (detected != currentMood) {
    currentMood = detected;
    playMoodMusic(currentMood);
  }
  // song ended and same mood continues: next song
  if (player.available() &&
      player.readType() == DFPlayerPlayFinished) {
    playMoodMusic(currentMood);
  }
  delay(3000);
}

Build in stages

  1. Music player

    Connect ESP32 and DFPlayer Mini. Test all five songs. Do this first.

  2. Camera

    Connect the OV2640 and confirm capture over Serial.

  3. Face detection

    Add a lightweight face detector.

  4. Mood recognition

    Add a quantized emotion model and test its accuracy.

  5. Automatic music

    Connect the prediction to the five songs.

Board advice

If you have not bought the camera yet, an ESP32-S3 with PSRAM is a better board for camera-based TinyML. If you already own the ESP32 DevKit, keep it: get music and camera working first, then add a small model.
